Running the Project
Open the Integrated Terminals:

Right-click the server folder and select Open in Integrated Terminal.

Right-click the client folder and select Open in Integrated Terminal.

Set up the Client:

In the client terminal, run the following commands:

npm install (This installs all required dependencies for the client)

npm start (This starts the client application)

Set up the Server:

In the server terminal, run the following command:

node server.js (This starts the server)

Database Configuration:

To access your chosen database, open db.js located at ./CS3320-main/server/config/db.js.

Update the MongoDB URI on line 6 with your connection string.
